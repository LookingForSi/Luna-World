# Luna World — Ingredient & Material Sources

Статус: рабочий reverse reference для loot/crafting economy.
Цель документа — быстро ответить на вопрос **«где добыть этот материал?»** и позже использовать ту же модель для in-game подсказок, codex/энциклопедии и tooltips у кузнеца.

Authoritative sources:
- `src/shared/definitions/ItemDefinitions.luau`
- `src/shared/definitions/LootTableDefinitions.luau`
- `src/shared/definitions/CraftingDefinitions.luau`
- для Ruins of Selene completion reward — `src/shared/dungeon/DungeonConfig.luau`

## Как читать вероятности

Для обычных ресурсов `resourceEntry(...)` в текущем runtime применяется множитель ×0.5.
В таблицах ниже уже указана **фактическая вероятность после этого множителя**.

`signatureResourceEntry(...)` не режется глобальным множителем. Поэтому, например, Магическая пыль с Гоблина-шамана имеет фактический шанс 100%.

## Только ингредиенты, реально используемые текущими рецептами

Текущая crafting-система прямо использует следующие материалы:

| Ингредиент | Ключевые источники |
|---|---|
| Волчья шкура | Молодой волк; Волк; Вожак стаи |
| Острый клык | Wolf family от Молодого волка до Альфы |
| Паучий шёлк | Ядовитый паук; Паук-матка; Лесной паук |
| Ядовитая железа | Spider family |
| Гоблинский жетон | Goblin family |
| Железный лом | Goblin Scout/Warrior; Скелет |
| Выделанная кожа | Лютые волки или переработка Волчьей шкуры |
| Прочная нить | Переработка Паучьего шёлка |
| Железная заготовка | Переработка Железного лома + Гоблинского жетона |
| Зачарованная нить | Переработка Прочной нити + Магической пыли |
| Магическая пыль | Гоблин-шаман; Павший служитель; Древний страж; Лунный страж |

Материалы `material_dire_hide`, `material_bone_fragment`, `material_fallen_relic` и `material_ancient_shard` уже существуют в economy/loot, но пока не входят в текущий набор рецептов.

## Кандидат для in-game UX

Позже эту информацию лучше не дублировать вручную в UI, а строить из authoritative definitions. Возможный UX:

- у недостающего ингредиента в окне кузнеца — действие **«Где добыть?»**;
- компактная подсказка: 2–4 лучших источника, зона, LV моба, шанс и количество;
- отдельная вкладка/экран **«Материалы»** в игровом codex;
- переход в обратную сторону: из карточки моба показывать его drop table;
- отдельно помечать **крафт**, **guaranteed/signature source** и **completion reward**, чтобы игрок не путал случайный дроп с гарантированной наградой.

Документ должен обновляться вместе с изменениями `LootTableDefinitions` / `CraftingDefinitions`; он не является отдельным источником баланса.
