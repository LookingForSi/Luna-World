# Luna World 0.1.0-beta.1

Дата: 2026-09-26

## Статус

Первый beta checkpoint целевой версии **0.1.0 Vertical Slice**.

Beta фиксирует состояние, в котором обязательный функциональный контур M0–M6 уже собран в `main` и локально принят. С этого checkpoint новые обязательные крупные системы в v0.1 не добавляются: работа переключается на published multi-place acceptance, regression, внешний playtest и release-sanity polish.

## Что входит

- Character Lobby и persistent progression;
- три стартовых архетипа;
- target-based PvE, skills, cooldowns и class resources;
- LV1–14 open-world progression Moonfall;
- quests Q1–Q7, map/tracker, merchant и No-Grade crafting;
- Party до 4 игроков с shared eligibility rules;
- production topology `Lobby → Moonfall World → Ruins of Selene`;
- Ruins of Selene: authoritative entrance, encounters, checkpoints/wipe/reset, Fallen Guardian, completion rewards, safe retreat и return flow;
- Studio-only `DevCombined` и debug tooling для owner acceptance.

## Что уже принято

- M5 Party & Multiplayer Hardening;
- M6 Ruins of Selene — локальный Studio / DevCombined owner acceptance;
- опубликованный Lobby → Moonfall transfer на реальном мобильном Roblox-клиенте;
- текущий mobile landscape gameplay UI baseline.

## Что beta ещё должна доказать

До `0.1.0-rc.1` обязательны:

1. Published `Lobby → Moonfall → Ruins → Moonfall` end-to-end acceptance.
2. Multiplayer smoke минимум `1 server + 2 clients`, включая party dungeon flow.
3. Persistence / rejoin / profile lease regression между Places.
4. Проверка отсутствия critical data-loss, reward duplication и remote-validation regressions.
5. Performance sanity.
6. Внешний playtest без подсказок разработчика.
7. Только blocker/usability fixes и минимальный release-sanity polish.

Если beta acceptance выявляет blockers, выпускается следующий `0.1.0-beta.x`. После прохождения gate — `0.1.0-rc.1`.

Финальный release gate отслеживается в GitHub Issue #63.
