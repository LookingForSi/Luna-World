# Luna World 0.1.0-rc.1 — 2026-09-27

Первый release candidate v0.1 после полного solo walkthrough на Ranger: прокачка до LV15, вся quest-chain, вход/выход из Ruins of Selene и завершение dungeon.

## Release-sanity polish

1. **Waypoint direction**
   - удалён нестабильный Unicode-глиф экранной стрелки;
   - для off-screen цели используются безопасные ASCII-направления `< > ^ v`;
   - расстояние остаётся в метрах.

2. **Quest / dungeon guidance**
   - transient-подсказки показываются 12 секунд и автоматически скрываются;
   - dungeon status смещён ниже target HUD;
   - текущая цель Ruins of Selene зеркалируется в журнал как «Текущее состояние»;
   - onboarding-подсказка кузнеца приведена к тому же 12-секундному policy.

3. **Ruins placement**
   - production dungeon опущен на 100 studs;
   - DevCombined isolation не меняется.

4. **Ruins ceiling & lighting**
   - у всех комнат добавлен сплошной потолок;
   - добавлены базовые настенные светильники с тёплым PointLight;
   - layout/gates/checkpoints/encounters не меняются.

## Acceptance перед stable 0.1.0

- published Lobby → Moonfall → Ruins → Moonfall;
- минимум 1 server + 2 clients;
- повторный вход и сохранение progression;
- mobile smoke;
- отсутствие blocker/data-loss/reward-duplication проблем;
- после acceptance — tag `v0.1.0`.
